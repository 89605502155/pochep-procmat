# Теория: модель M t = p и матричные разложения

Пусть `M` матрица размера T × r: строка соответствует моменту времени, столбец процессу, элемент
равен потреблению памяти процессом в этот момент. Вектор `p` длины T содержит суммарное потребление
памяти. Вектор `t` длины r содержит неизвестные веса процессов. Модель `M t = p` ищет `t` так,
чтобы взвешенная сумма профилей процессов совпала с измерением.

Если `T > r` и столбцы `M` линейно независимы, решение по методу наименьших квадратов единственно.
В этом случае решение через QR дает `t = R^{-1} Q^T p`, где `M = Q R`, `Q` имеет ортонормированные
столбцы, `R` верхнетреугольная. Если столбцы зависимы, `R` вырождена, и решение через QR не существует.
Тогда используется SVD: `M = U diag(s) V^T`, и минимальное по норме решение равно `V diag(1/s) U^T p`,
где малые сингулярные значения отбрасываются по порогу `rcond`.

Метод нормальных уравнений `(M^T M + λ I) t = M^T p` решается разложением Холецкого. Положительный
параметр `λ` (ridge) делает систему разрешимой при вырожденной `M`. Цена метода в том, что число
обусловленности возводится в квадрат.

Если веса процессов должны быть неотрицательными, решается задача `min ||M t - p||` при `t >= 0`
(NNLS). В пакете она решается проекционным градиентом с шагом `1/L`, где `L` наибольшее собственное
значение `M^T M`.

Неотрицательное матричное разложение (NMF) ищет `M ~ W H` с `W >= 0` и `H >= 0`. Столбцы `W`
можно интерпретировать как латентные профили, а строки `H` как доли этих профилей в процессах.
Разложение находится итерациями Ли и Сына (мультипликативные обновления). Оно не единственно,
поэтому результат зависит от начального приближения `seed`.

Квантор всеобщности (∀) здесь означает: для любого момента времени t_i выполняется уравнение
Σ_j M_ij t_j = p_i с точностью до шума. Квантор существования (∃) означает: существует такой
вектор весов t ≥ 0, что ||M t - p|| минимально (задача NNLS).

Пакет не гарантирует, что найденные веса соответствуют реальным процессам. Это гипотеза эксперимента,
а не свойство разложений. См. `НОВИЗНА.md` и `АНАЛИЗ.md` статьи.
